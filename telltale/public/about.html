About

A detector that shows its work

Detectors have become gatekeepers — in classrooms, in hiring pipelines, in editorial inboxes — while remaining black boxes that quote a confidence percentage nobody can audit. TellTale is the opposite bet: a small, readable engine whose every measurement you can inspect, argue with, and change.

Principles

  • 1Show the reasoning. Every point of the score is attributed to a named signal with a measurement beside it.
  • 2Abstain honestly. Short, thin or contradictory evidence produces "inconclusive", not false confidence.
  • 3Local by default. No third-party APIs, no telemetry, no hidden model calls. Your text stays on the machine running this.
  • 4Never punitive. The output is designed to start a conversation, and says so at the bottom of every report.

Engineering

  • ·Runtime: Node 18+, standard library only. No framework, no build step for the server, no dependencies to audit.
  • ·Frontend: vanilla JavaScript. The same engine file scores text live in the browser as you type, so previews and reports can't disagree.
  • ·Storage: a JSON file (data/scans.json), capped at 400 scans, each keeping its full evidence pack. Delete it and there is nothing left.
  • ·Tests: a calibration harness, a register/paragraph suite, a docs-number generator that keeps published figures honest, and a headless UI smoke test that drives every page.
  • ·Speed: a few milliseconds per analysis; the network is the slow part.

Run it yourself

Clone the folder, start the process, open the port. That's the whole setup.

# no install step — zero dependencies node src/server.js # → http://localhost:4173 # optional: regenerate the browser engine bundle node scripts/build-client.js # optional: see the calibration harness node scripts/selftest.js

API

The UI is just a client of these endpoints. Everything it can do, you can do with curl.

EndpointWhat it does
POST /api/analyze{ "text": "…", "save": true, "register": "academic" } → full report: score, verdict, confidence, register + calibration, 14 signals, paragraph report, sensitivity, heatmap segments, spans, recommendations. register is optional — omit it for auto-detection.
GET /api/registersThe available scoring profiles with their weight adjustments, discount factors and phrase relaxation.
POST /api/reportExport an unsaved report: { "text": "…", "format": "md" | "json" } → Markdown evidence pack or signed JSON bundle (download headers included).
GET /api/report/:idSame exports for a stored scan, with ?format=json&label=….
POST /api/verifyRe-computes the SHA-256 digest of a JSON bundle and reports whether it has been modified.
POST /api/compare{ "texts": [{ "label", "text" }, …] } → compact results for 2–4 texts on identical scales.
GET /api/sample?kind=aiServes a built-in sample (ai, human, mixed).
GET /api/history?limit=25Recent scans without their full text.
GET /api/scan/:idOne stored scan including the original text.
DELETE /api/scan/:idDelete a single scan.
GET /api/statsAggregates for the dashboard: distribution, shares, recurring phrases, feed.
POST /api/clearWipe all stored scans.

Ethics

Automated authorship detection has a documented history of harming people: false accusations against students, bias against non-native English writers, and confident numbers attached to ambiguous evidence. TellTale is built to reduce that harm, not to industrialise it. If you are using this to evaluate another person, you owe them the reasoning, a chance to respond, and a decision process that doesn't rest on a single score.

Shipped

  • ✓Per-paragraph reports with mixed-authorship detection, so a generated intro on a human body can't hide behind an average.
  • ✓Register calibration for academic, legal, technical, journalistic and personal writing — detected from genre markers or set manually, with the before/after delta always disclosed.
  • ✓Evidence packs: Markdown reports and JSON bundles with a SHA-256 integrity digest, verifiable via POST /api/verify.
  • ✓Score-sensitivity analysis: how far the verdict moves when the strongest signal is withdrawn.

What's next

  • →An adversarial test suite that measures how far a paraphrase pass can move the score — and publishes the answer.
  • →Batch mode: score a folder of submissions and rank by machine-likelihood with paragraph outliers surfaced.
  • →Register-specific phrase lists so "however" is judged by the genre it appears in rather than a global rule.
TellTale is a self-contained demo project: MIT licensed, no accounts, no analytics, no third-party services. One Node process, one JSON file, one HTML report at a time.
